Objective and Payload Generators

Mission objectives are created using generator functions that follow a consistent pattern. Each function returns an objective table with a `type` field and a `conditions` table containing parameter strings.

Objectives can be simple (requiring just a type) or complex (requiring multiple parameters like regions, factions, or an amount).
